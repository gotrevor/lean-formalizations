# papers/

Local source PDFs for the formalizations. **PDFs are gitignored** (`*.pdf`) — this
repo is eventually-public, so we don't redistribute copyrighted full-text. Commit
only citations + summaries (see `../SOURCES.md`).

Present locally (not tracked):
- `Curtis-1990-Frobenius-formula.pdf` — Math. Scand. 67 (1990), 190–192. Free
  open-access copy from https://www.mscand.dk/article/download/12330/10346.
- `sun-2026-catalan-irrationality.pdf` — Zhi-Wei Sun, *Catalan's constant is
  irrational*, arXiv:2609.04176v1 (3 Sep 2026). **The proof is wrong**; see
  `sun-2026-catalan-irrationality.md` for the refutation, the salvage (Thm 2.1),
  and `sun-2026-catalan-twoadic-check.py` for the exact-rational check.
