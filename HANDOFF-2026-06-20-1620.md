## 🧠 The math (what got proven this lap, from scratch)
Two analytic cruxes that the prior handoff left as disclosed `sorry`s, both now machine-checked:
- **(b1) Fourier half-period shift** `‖𝓕 f u‖ ≤ ½∫‖f t − f(t+1/(2u))‖`. Write `𝓕` via `fourier_eq'` in the
  `Complex.exp(↑r·I)` phase form (norm 1 by `Complex.norm_exp_ofReal_mul_I`); shift by `h=1/(2u)` with
  `MeasureTheory.integral_add_right_eq_self`; the phase picks up `exp(−πI) = −1` so the shifted integral is
  `−𝓕 f u`; add the two reps to get `2·𝓕 f u = ∫ c v·(f v − f(v+h))`, then `norm_integral_le_integral_norm`
  with `‖c‖=1`. Integrability via `Integrable.bdd_mul`.
- **(b2) L¹-translation by total variation** `∫‖f t − f(t+h)‖ ≤ |h|·V`, for ALL `h`. KEY IDEA that made it
  mathlib-reachable: avoid the **signed** variation measure (mathlib-absent) by using the **monotone
  variation function** `W(t) = (eVariationOn f (Set.Iic t)).toReal`. Proven pieces:
  - `varFn_mono` / `varFn_nonneg` / `varFn_le_V` — `W` monotone, in `[0, V]`.
  - `norm_sub_le_varFn_sub` — pointwise `‖f t − f(t+h)‖ ≤ W(t+h) − W(t)` (h≥0), via
    `eVariationOn.add_le_union` (superadditivity on `Iic t ⊎ Icc t (t+h) = Iic (t+h)`) + `eVariationOn.edist_le`.
  - `integrable_and_integral_varFn_diff_le` — the analytic core, **NO Stieltjes measure**: the finite window
    telescopes `∫_{−N}^{N}(W(·+k)−W) = ∫_N^{N+k}W − ∫_{−N}^{−N+k}W ≤ k·V − 0`
    (`intervalIntegral.integral_comp_add_right` + oriented `integral_add_adjacent_intervals` + `W≤V`/`W≥0`);
    the bound is uniform in `N`, so the nonneg integrand is integrable
    (`integrable_of_intervalIntegral_norm_bounded`) and `∫_ℝ = lim_N ∫_{−N}^{N} ≤ k·V`
    (`intervalIntegral_tendsto_integral` + `le_of_tendsto`).
  - `integral_norm_sub_translate_le` — full (b2): nonneg case by `integral_mono_of_nonneg` + pointwise bound;
    `h<0` folds to `h≥0` by translation + `norm_sub_rev`.
