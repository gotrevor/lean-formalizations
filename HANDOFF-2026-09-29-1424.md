## 🧠 Context to carry forward

**The one real insight this lap, and it generalizes.**  Phase 16 proved Schanuel ⇒ four
exponentials through `Exponentials.false_of_exp_algebraic_of_quad`, stated with
`hS : SchanuelConjecture`.  But that 150-line proof consumes `hS` *only* through
`algebraicIndependent_of_exp_isAlgebraic` — which is literally Conjecture 1.  So the honest
strength of the phase-16 result was always Conjecture 1, not Schanuel.  `false_of_exp_algebraic_of_quad'`
is that same proof with the hypothesis weakened exactly that far, which is what the survey
actually claims.  **Lesson worth reusing: before assuming a derivation needs the big conjecture,
check which lemma actually touches the hypothesis.**  Several phase-15/16 results may be
similarly over-hypothesized.

The body is *duplicated* rather than refactored, deliberately: phase 16's names are frozen, so
generalizing the original in place was not allowed.  If a future phase is permitted to touch
`Exponentials.lean`, the right cleanup is to restate the phase-16 lemma over `AlgIndepLogsConjecture`
and derive the `hS` version from `algIndepLogs_of_schanuel`, deleting the copy.

**Second thing worth knowing**: Conj 1 ⇒ Baker's homogeneous theorem is *pure field theory* —
`AlgebraicIndependent.extendScalars` moves independence from ℚ to ℚ̄ (legitimate since ℚ̄/ℚ is
algebraic), then phase 15's `eq_zero_of_algebraicIndependent_linear` at base ℚ̄ kills the affine
relation.  No analytic input at all.  That is a slightly surprising amount of Baker for free.

**No approach was abandoned this lap** — all five went through on the first serious attempt, and
no statement turned out to be false or underivable.  The only friction was tactic-level (see
Gotchas).

## ⚠️ Gotchas

- **`LinearIndependent ℕ`**: `linearIndependent_unique_iff` and `Fintype.linearIndependent_iff`
  both need a `Ring`, so ℕ is excluded.  Use the `ₛ` semiring variants (`linearIndependent_iff'ₛ`).
- **`IsAlgebraic.tower_top` into `↥(integralClosure ℚ ℂ)`** demands a `Field` instance it cannot
  get.  Use `he.extendScalars (S := integralClosure ℚ ℂ) (algebraMap ℚ _).injective`.
- **`simp` rewrites `((Real.log 2 : ℝ) : ℂ)` to `Complex.log 2`** via `Complex.ofReal_log`, which
  silently derails `Complex.im`/`re` computations.  Tight `simp only` list, then `norm_num`.
- **`π` is not in scope** without `open Real`; write `((Real.pi : ℝ) : ℂ)`.
