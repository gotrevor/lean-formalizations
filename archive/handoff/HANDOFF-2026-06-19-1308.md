**Goal:** `mertens_second : (fun N ↦ primeRecipSum N − Real.log (Real.log N)) =O[atTop] (fun _ ↦ 1)`.
Every nontrivial fact is already proved & axiom-clean; what's left is measure-theory plumbing.
From `mertens_second_identity`:
`primeRecipSum N − log log N = primeSumDiv N/log N + (∫_2^N primeSumDiv⌊t⌋₊/(t log²t)) − log log N`.
- Split the integrand `primeSumDiv⌊t⌋₊/(t log²t) = (log t)/(t log²t) + (primeSumDiv⌊t⌋₊ − log t)/(t log²t)`
  = `1/(t log t) + r(t)/(t log²t)`.
- **Integrability bookkeeping** (the only new work): show on `Ioc 2 N`
  (i) `IntegrableOn (fun t ↦ 1/(t log t))` (continuous on `[2,N]` — cf. `integral_inv_log_mul`'s `hcont`);
  (ii) `IntegrableOn (fun t ↦ (primeSumDiv⌊t⌋₊ − log t)/(t log²t))` — numerator is a measurable step
  function (`t ↦ primeSumDiv⌊t⌋₊` = `primeSumDiv ∘ Nat.floor`, measurable) bounded by `C`
  (`abs_primeSumDiv_floor_sub_log_le`), times the continuous `1/(t log²t)`; bounded measurable on a bounded
  interval ⇒ integrable. Then `integral_add` splits the integral.
- **Main term:** `∫_2^N 1/(t log t) = log log N − log log 2` (`integral_inv_log_mul` with a=2,b=N; note
  `(log t)/(t log²t) = 1/(t log t)`).
- **Remainder:** `|∫_2^N r(t)/(t log²t)| ≤ ∫_2^N |r|/(t log²t) ≤ C·∫_2^N 1/(t log²t) = C(1/log2 − 1/log N) ≤ C/log2`
  (`abs_primeSumDiv_floor_sub_log_le` + `integral_inv_mul_sq_log` + `norm_integral_le_integral_norm` /
  `integral_mono`).
- **Assemble:** `primeRecipSum N − log log N = primeSumDiv N/log N − log log 2 + R(N)`, with the first term
  `→1` (bounded) and `|R(N)| ≤ C/log2` (bounded) ⇒ `=O[atTop] 1`. (For the cleaner `Tendsto` form, also need
  `R(N)` and the boundary term to converge — the `=O 1` form is the lower-effort target; do it first.)
