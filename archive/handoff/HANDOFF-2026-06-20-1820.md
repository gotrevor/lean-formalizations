## 🧠 The one open item — and why it does NOT block completion
The sole remaining repo-connected open target is the **sharp `2π|u|`** BV-Fourier decay constant for
`prelim_decay_2/3` (we have the non-sharp `4|u|`/`8π·u²` complete + axiom-clean in
`src/.../BVFourierDecay.lean`). I worked it as a research problem this lap:
- **Traced the full sharp proof.** `2·𝓕f(u) = ∫ e(−tu)(f(t)−f(t+h)) dt` with `h=1/(2u)` (this is our
  already-proven (b1), exact, before taking norms). Writing `f(t)−f(t+h) = −∫_{(t,t+h]} df` and applying
  **Fubini**: `∫_{s−h}^{s} e(−tu) dt = −e(−su)/(πiu)` (using `e(½)=−1`), so the whole thing collapses to
  `𝓕f(u) = (1/(2πiu)) ∫ e(−su) df(s)`, giving `‖𝓕f(u)‖ ≤ V/(2π|u|)`. **This recovers the sharp constant.**
- **Pinned the exact missing mathlib primitive:** the **signed Stieltjes measure** `μ_f` of a BV function
  with `μ_f((a,b]) = f(b)−f(a)`. mathlib has this only for **monotone** `f` (`StieltjesFunction.measure`,
  `measure_Ioc`). For signed/BV you must build `μ_f = μ_g − μ_h` (Jordan, `f=g−h`) and the IBP/Fubini on
  top — a development **absent from mathlib** (exists only externally: Luccioli–Degenne
  `testing-lower-bounds/ForMathlib/ByParts.lean`; verified online 2026-06-19, see reference corpus note
  `2026-06-19-pntand-prelim-decay-still-open-upstream.md`).
- **Verdict: 🟠 generational wall, off-headline.** It gates **no headline** (the upstream `prelim_decay`
  sorries in the PNTAnd dep are dead code off the `weakPNT` path — `#print axioms weakPNT` is clean with
  them present). Its feasible weaker form is already in `src/`. So it is **not a chippable 🟡** — it's a
  multi-lap missing-theory build. Building it to sharpen an off-headline bonus is exactly the side quest
  the operator's finish-and-stop directive forbids.
