## 🧠 Context to carry forward
The whole phase turns on one observation: write `C_k = 3^a · largeC j′ s′ k` (`def threePowC`), and
every hypothesis Saito's Type B theorem asks for is **scale-invariant**. So (B1)–(B3) and the
delicate (B5′) transfer from phase 58's `largeC` lemmas mechanically — `threePowC_ratio_of_largeC`
scales the `29/10` bound, `threePowC_B5` is `largeC_B5` plus `Nat.mul_dvd_mul_left`. Crucially
Euler then runs on the 3-free part `D_m = C_m / 3^a`, never on `C_m` itself, which is exactly the
step that dies when `3 ∣ s`. Almost no new mathematics was needed; the win was picking the right
factorization of the exponent sequence.

Two pieces that were genuinely new, and worth remembering:
1. **`a < j` is forced, not assumed.** `8·3^a ≤ 3^a s′ ≤ 3^(j+1)`, whereas `j ≤ a` would give
   `3^(j+1) ≤ 3·3^a < 8·3^a`. That is what licenses `j = a + j′` with `j′ ≥ 1` and `s′ ≤ 3^(j′+1)`.
   I had expected to need `a < j` as an extra hypothesis on the frozen statement; it isn't.
2. **The Saito period bound weakens from `g = 1` to `g ∣ 3^a`**
   (`dvd_three_pow_of_eventually_dvd`): `g ∣ 3C_k − C_(k+1) = 3^a·2s′`; `C_k` is odd (both factors
   odd) so `g` is odd, so `g ∣ 3^a s′`; then `g ∣ C_k − 3^a s′ = 3^a·3^(k+j′)`, and
   `Nat.gcd_mul_left` with `3 ∤ s′` gives `gcd(3^a s′, 3^a 3^(k+j′)) = 3^a`. `Nat.dvd_prime_pow`
   turns that into `g = 3^b`, `b ≤ a`. After `threePowC_split`/`_div` show
   `C_k / 3^b = threePowC (a−b) j′ s′ k = 3^(k+(a−b+j′)) + σ` with `σ = 3^(a−b) s′ ≥ 8`, the Pisot
   number `β = ξ^(3^b)` sits in *exactly* phase 58's endgame and both branches
   (`f ≢ X³ mod 3` via Theorem D; `f ≡ X³ mod 3` via 3-divisible traces) reuse
   `four_lt_pisot_pow`, `floor_pow_prime_pow_add_not_prime_full`, `powTrace_eq_traceSeq`,
   `dvd_traceSeq_of_map_eq_X_pow` verbatim.

Assumption carried, unchanged from phase 58: the `s′ ≥ 8` is there only to make Siegel's
`κ^8 > 4` reach Theorem D's size condition `β^σ > d+1 = 4`. It is not intrinsic.
