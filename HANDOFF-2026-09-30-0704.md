## 🧠 Context to carry forward

**The header's proposed route is not the route I used, and the difference matters.**  The file header
proposed the lifting step `X = Y + c^e Z ⟹ X^c ≡ Y^c (mod c^(e+1))` via the binomial expansion plus
`c ∣ binom(c,i)`.  That drags in a matrix `Z` (which then needs `Commute Y Z`, obtained only by
cancelling a `c^e` smul) *and* binomial-coefficient divisibility.  All of it is avoidable:

> `Commute.geom_sum₂_mul` gives `X^c − Y^c = (∑_{k<c} X^k · Y^(c−1−k)) · (X − Y)` for commuting `X`,
> `Y`.  If `X ≡ Y (mod c)` then mod `c` every one of the `c` summands of the cofactor collapses to
> `Y^(c−1)`, so the cofactor `≡ c·Y^(c−1) ≡ 0 (mod c)`.  Multiply by `c^e ∣ X − Y` **entrywise**
> (`Matrix.mul_apply` + `Finset.dvd_sum` + `mul_dvd_mul`) and you land on `c^(e+1)` with no `Z`, no
> smul bookkeeping and no binomial coefficients.

That is `pow_congr_lift`, and it's the reusable artifact: it takes **two commuting matrices**, unlike
phase 41's `SmulDvd.pow_prime_pow` (`FibonacciCoveringAllPrimes.lean:318`) which is relative to `1`.
If a later phase needs LTE between two arbitrary powers of `A`, use the new one.

The mod-`c` base step is `SharedConjecture.exists_trace_pow_congr` almost verbatim: reduce to
`ZMod c`, `Matrix.isUnit_iff_isUnit_det`, get a unit `u`, `N = Nat.card (GL (Fin d) (ZMod c))`,
split `N = c^a · M` with `a = N.factorization c` (`Nat.ordProj_mul_ordCompl_eq_self`,
`Nat.not_dvd_ordCompl`), then `f = φ(M)` and `Nat.ModEq.pow_totient`.  I generalised that file's
single index `m` to "for every `n ≥ a`" — needed, because the induction consumes every level.

Then `Nat.le_induction` on `n ≥ a` with `A^(c^(n+1+f)) = (A^(c^(n+f)))^c`.  The exponent arithmetic
`n − a + 1 + 1 = n + 1 − a + 1` is `omega` (it needs `a ≤ n`, hence the induction hypothesis form).

**Interpretation for R2 downstream**: `f` and `a` are explicit — the limit points are the `f` values
`lim_m A^(c^(a+r+mf))`, `r < f`, and `f ∣ φ(ord_compl[c] |GL_d(𝔽_c)|)`.  That bound on `f` is free
if a later phase wants it.
