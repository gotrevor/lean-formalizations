direction `θ` covers length `≥ 1` in the cover. Prior laps proved the cover's covered-length graph is
**Borel** and concluded selection needed von Neumann (Borel sections, not closed → KRN inapplicable).

**The escape: route the content bound through an OPEN cover.** For an *open* target `F`:
- a unit segment is **compact**; a compact set inside an open set has a **tube neighbourhood** inside
  it (`IsCompact.exists_thickening_subset_open`);
- so *any* base point within that tube — in particular one from a **fixed countable dense sequence**
  (`TopologicalSpace.denseSeq`) — has its *entire* segment in `F`, i.e. covered length **exactly 1**;
- the "first dense point that works" selector is **measurable** (`measurable_find` over the total
  `∀ θ, ∃ n` witness + `measurable_coveredLength` for each section).

No selection theorem, no analytic sets. (The concurrently-delivered findings doc
