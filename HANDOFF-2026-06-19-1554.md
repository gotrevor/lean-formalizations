## 🧠 Context to carry forward
- **The construction is a 12-of-16-block "pinwheel," NOT stacked arcs.** Take ONE hyperbola
  `H(k,p)={xy≡k mod p}` over `[0,2p)²`. Each nonzero residue `r∈[1,p)` (with `s=hyperbolaY p k r`)
  occupies the 4 corners of a `p×p` square: `(r,s),(r+p,s),(r,s+p),(r+p,s+p)`. **Keep 3 of the 4 per
  class** ⇒ `3(p−1)` points. The harvested findings doc is in `archive/findings/` — re-read §1.4–1.5
  (the family layout) and §2 (the slope argument) before attacking the crux.
- **THE KEY SIMPLIFICATION I verified: slopes 0/∞ are AUTOMATICALLY safe.** Each row `y=h` (resp.
  column) hits only the unique class whose `y`-residue (resp. `x`-residue) is `h mod p` — because the
  residue determines the class (`s ↔ r=k·s⁻¹` is a bijection). So any horizontal/vertical line carries
  ≤ 2 pinwheel points. **The entire crux is therefore the slope-±1 case only.**
- **Reduction chain (all machine-checked now):** general HJSW Lemma (`hyperbola_line_two_congruent`) ⇒
  any collinear triple has two CONGRUENT points (= same class). If all three same class ⇒
  `pinCorner_not_collinear` (rectangle, det=±p²) kills it. So every collinear triple is **two corners
  of class `r` + one corner of class `r'≠r`**, and (slope 0/∞ excluded) the two same-class corners are
  the surviving **±1 diagonal**. The two classes `r,r'` on a ±1 line are **σ-reflections** of each
  other (proved: `hyperbola_slope_one_reflection` gives `r'=−s,s'=−r,rr'=−k`; the −1 companion gives
  `r'=s,s'=r,rr'=k`). HJSW's family-assignment drop-rule routes the two σ-paired classes to
  *complementary* slope-families so only ONE keeps the on-line diagonal — that's what defeats the
  incidence.
- **Why I stopped before the drop-rule:** defining the exact family rule in `[0,2p)²` (translating
  HJSW's centered `T'_{2p}` frame, §1.3) is error-prone, and a WRONG rule yields an unprovable goal
  that looks fine until the incidence step. Better to pin it carefully next lap with the findings open
  than to rush a fragment at lap end. All the plumbing it needs is already proved.
